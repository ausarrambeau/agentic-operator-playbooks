# The eight moves

Eight things that make a set of notes act instead of sit there. Each one is
running daily. The rule under each move is the exact wording to paste into
your assistant — none of it needs my setup.

## 1. Wake up to the day sorted.

Something writes my summary at 6am. I just read it.

```
Every morning, before I ask anything: tell me what changed since yesterday, what's stuck, and the one thing to do first. If you can't find something, say so instead of guessing.
```

## 2. Stop repeating yourself.

Every new chat already knows what I've decided before.

```
At the start of every chat, read my notes and load anything that matters for what I'm working on. Then tell me what you read and what you skipped.
```

## 3. A memory it can't quietly change.

Every decision gets written down and numbered. Old ones never get edited.

```
When we decide something, add it as a new numbered line with the date. Never edit an old line — add one saying it replaces it.
```

## 4. Keep score of its guesses.

It says how sure it is. Later I write down what actually happened.

```
When you recommend something, tell me how sure you are out of ten. Later, write down what actually happened next to your guess.
```

## 5. Make the limit a wall.

I give it a budget. It stops there and tells me why.

```
Before a big job, tell me what it will cost. Treat my number as a hard limit — when you reach it, stop and tell me.
```

## 6. Make it prove it's better.

Before it changes how it searches my notes, it has to beat the old way.

```
Before changing how you search my notes, run the same twenty questions both ways, show me both, and only switch if the new one wins.
```

## 7. Teach it to stop.

It can read and draft anything. Sending or spending needs a yes.

```
You can read and draft anything. Sending, posting, deleting and spending need me to say yes each time — then stop and wait.
```

## 8. It tidies up while you sleep.

Overnight it sorts everything and leaves me a short list to check.

```
Once a day, re-read what we added, fix what no longer lines up, and leave anything you're unsure about in a list for me.
```

---

That's all eight. Nothing here needs my setup — paste any
of them into whatever assistant you already use.
